# Inventory Joy

Crie um sistema de controle de estoque a partir das instruções do markdown anexado. Por favor, crie também um arquivo de migração SQL inicial ou configure os scripts do Supabase diretamente para estruturar as tabelas products, customers, sales e sale_items com as políticas de RLS ativadas.
